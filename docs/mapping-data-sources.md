# Mapping and data providers

The map uses [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/docs/) with the [OpenFreeMap](https://openfreemap.org/) Liberty style. OpenFreeMap's public instance is free, requires no API key, and currently advertises no request limit; it does not offer an SLA. Its style attribution is enabled and credits OpenMapTiles and OpenStreetMap. The map can use another compatible style by setting the public `VITE_MAP_STYLE_URL` build variable. Map tiles are requested by the browser, so the tile host receives the visitor's IP address and requested map area; OpenFreeMap says it does not use cookies or a user database.

Routing uses an [OSRM-compatible service](https://project-osrm.org/). The default is `https://router.project-osrm.org`; deployments can set the server-only `OSRM_ROUTING_URL` to a self-hosted or contracted endpoint. The public demo server asks clients to avoid excessive use, may block destabilizing traffic, requires attribution and an identifying User-Agent, and provides no availability or quality guarantees. This app sends an identifying User-Agent. OSRM supports road, bicycle, and foot profiles only when the chosen server has them loaded. Two-wheeler currently uses the general driving profile. Transit is disabled because no GTFS transit feed is configured. Do not rely on the public demo for commercial or high-volume traffic. If the provider is offline or returns no route, route scoring stops and the UI reports that no route is available instead of drawing a synthetic route.

Place search, current AQI, and weather use [Open-Meteo](https://open-meteo.com/en/terms). Its air-quality API describes model-based current conditions and CAMS forecasts at roughly 11–45 km resolution; the map's India points are sample coordinates, not ground monitors. GPS reverse-geocoding uses [Photon](https://photon.komoot.io/); the user's coordinates are sent to that service when resolving a location label. Photon asks API users to be fair, may throttle extensive use, and offers no availability guarantee. If it is unavailable, the UI labels the place as unknown rather than inventing a name. AQI/weather map markers represent returned point estimates; they are not a continuous satellite or station-derived heatmap. Open-Meteo's free API is limited to non-commercial use and publishes request limits of 10,000 calls/day, 5,000/hour, and 600/minute. Its limits apply by IP and application, so server-side proxy traffic shares the deployment's quota. The app caches the Pan-India grid for five minutes; local and route telemetry are not cached. Data requires [CC BY 4.0 attribution](https://open-meteo.com/en/licence), shown below the map. Commercial deployments need an Open-Meteo subscription or a separately licensed provider.

OpenStreetMap data is licensed under the [ODbL](https://www.openstreetmap.org/copyright) and requires attribution. The public OpenStreetMap tile service is not used. [Nominatim](https://operations.osmfoundation.org/policies/nominatim/) is not used: its public instance is limited to one request per second and prohibits client-side autocomplete. The selected providers are external services without a guaranteed end-to-end availability SLA. Configure alternatives and adequate caching/rate controls before relying on this stack for production traffic.

Route coordinates and requested AQI/weather sample coordinates are sent from the server to OSRM and Open-Meteo; those providers see the deployment server's IP and the requested areas. Photon receives coordinates for GPS reverse-geocoding. Map tile requests go directly from the browser to OpenFreeMap, which sees the visitor's IP and map area. Optional Gemini summaries send route labels, coordinates, and sampled telemetry only when the user supplies a Gemini key.

Google Maps Platform is not used for map rendering, search, routing, AQI tiles, or weather. Gemini remains optional and uses the user's own key only.
